# Backend 

Представляет собой последний узел процесса конвейера автоматона

Основная задача бэкенда сгенерировать итоговый выход из семантической модели теста и интегрировать его в назначенное место

Бэкенд представляет из себя две компоненты (в основном):

* Генератор. Генерирует итоговый автотест из семантической модели. Отвечает на вопрос "Как должен выглядеть автотест?"
* Интегратор. Поставляет сгенерированный автотест в нужное место. Отвечает на вопрос "Где должен храниться автотест?"

Существуют исключительные варианты бэкендов, как например AllureTestOpsBackend (concept), который не имеет отдельного и интегратора, так как
занимается преобразованием семантической модели в собственный API и сам же его и поставляет в хостинг
